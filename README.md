# Sales & Profit Analysis Using Python

## Project Overview

This project analyzes sales and profitability data from the Global Superstore dataset using Python.

The goal is to clean the raw data, explore sales and profit performance, visualize key patterns, and turn the results into business insights.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow

1. Import libraries
2. Load the dataset
3. Explore the data
4. Clean and prepare the data
5. Perform exploratory data analysis (EDA)
6. Analyze sales, profit, products, customers, regions, time, and discounts
7. Create visualizations
8. Extract business insights
9. Summarize the findings

## Key Analysis Areas

- Overall Sales, Profit, Quantity, and Profit Margin
- Category performance
- Regional performance
- Customer performance
- Product performance
- Top and bottom products
- Yearly and monthly sales trends
- Discount vs. average profit
- Discount vs. average sales

## Key Insights

- 2014 recorded the highest sales and the highest profit in the analyzed period.
- The Central region generated the highest sales, but higher sales did not necessarily mean higher profitability.
- Higher discount levels were generally associated with lower average profit.
- Discount levels did not show a clear positive relationship with average sales.
- Some products generated high sales with relatively low profit, showing why sales should not be evaluated without profitability.
- Large negative-profit observations were treated as potential business cases for investigation rather than automatically removed as errors.
